# Helios Ledger Connector

General-ledger entry streaming with reversal tracking for Helios Ledger.

## Events

- `ledger.entry_posted`
- `ledger.entry_reversed`
- `ledger.balance_snapshot`
- `connector.health`

## Authentication

`oauth2`
